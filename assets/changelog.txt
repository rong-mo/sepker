[lightgray]  - 黑框从第一次显示起常驻屏幕底部（只有「暂停」或离开地图才关闭），从文本缓冲区打字机式打印；宽度随文本自适应（至少 3 行），左上角小黑框显示名字

[lightgray]  - 选择也排进同一个缓存队列：等前面的句子都切完才出现；在它出现并被点选之前，处理器一直阻塞

[lightgray]  - 指令里新增「变量」输入框：点选结果以字符串写进该逻辑变量（选项文字本身，覆盖旧值；逻辑里可直接和 "选项文字" 比较）
[lightgray]  - 暂停：也排在缓存末尾，等前面的句子都点完才关闭（期间处理器阻塞）；没有缓存时立即关闭
[lightgray]  - 旧的 fastmessage 写法（notify / announce / toast / mission）保持兼容

[lightgray]• Fast Message: new "dialog" type
[lightgray]  - Talk / Choose / Pause, cycled by one button
[lightgray]  - The black box stays on screen from its first line (only Pause or leaving the map closes it); it typewrites the text buffer, fits the text (minimum 3 lines), with a small black name plate at its top-left
[lightgray]  - The name is entered in the instruction and always overrides
[lightgray]  - Talk does not block: each execution queues that line into a buffer; tap the screen or the "Continue" button right of the name to finish the current line, tap again for the next queued line
[lightgray]  - Choices join the same queue: they appear only after all earlier queued lines have been advanced, and the processor stays blocked until the choice is shown and picked
[lightgray]  - Choose: the text is replaced by option buttons; one text field per option in the instruction, "+" at the bottom-right adds more (2-8)

[lightgray]  - Pause: queued after the cached lines; closes only after they have all been advanced (the processor stays blocked meanwhile); closes immediately when there is no cache
[lightgray]  - The old fastmessage syntax (notify / announce / toast / mission) still works
