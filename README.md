# 黄队的奇妙大冒险（Sepker）

> 一个**剧情向**的 Mindustry 模组：新增自定义星球「赛普克尔」。
> A **story-driven** Mindustry mod featuring the custom planet **Sepker**.

## 模组信息 / About

| 项目 | 内容 |
|---|---|
| 名称 | 黄队的奇妙大冒险 |
| 内部 ID | `sepker` |
| 类型 | 剧情 / 星球（Story / Planet mod） |
| 适配版本 | Mindustry **v8**（`minGameVersion: 159`） |
| 最新版本 | **V0.6.10** |
| 作者 | rong-mo |
| 语言 | 简体中文 / English |

## 安装 / Install

1. 从 [Releases](../../releases) 下载最新的 `V<版本>.jar`
2. 游戏主菜单 →「模组」→「导入模组」→ 选择该 jar
3. 回到主菜单，进入「赛普克尔」星球

也可以在游戏「模组」→「从 GitHub 导入」里填：

```
rong-mo/sepker
```
