# 黄队的奇妙大冒险（Sepker）

> 一个 Mindustry 模组：新增自定义星球「赛普克尔」，围绕铀矿展开的生产链、方块、单位与逻辑指令。
> A Mindustry mod adding the custom planet **Sepker**, with a uranium-based production chain, blocks, units and logic instructions.

## 模组信息 / About

| 项目 | 内容 |
|---|---|
| 名称 | 黄队的奇妙大冒险 |
| 内部 ID | `sepker` |
| 类型 | 星球 + 内容扩展（Planet / Content mod） |
| 适配版本 | Mindustry **v8**（`minGameVersion: 159`） |
| 最新版本 | **V0.6.10** |
| 作者 | rong-mo |
| 语言 | 简体中文 / English |

## 内容 / What it adds

- **星球**：赛普克尔，4 个扇区 —— 边陲废墟、沙漠之心、侵蚀洞窟、遥远的桥
- **物品**：铀系产物，含贫铀、相织布等
- **方块**：采矿、精炼、发电、物流与防御一整套，含亚空间传送带、相织脱贫器、大型冷冻液混合器
- **单位**：空中与地面单位若干（含玩家可操控机型）
- **逻辑**：世界处理器扩展指令 `fastmessage`
- **战役**：自定义三级难度（正常 / 困难 / 毁灭）与战役规则面板

## 安装 / Install

1. 从 [Releases](../../releases) 下载最新的 `V<版本>.jar`
2. 游戏主菜单 →「模组」→「导入模组」→ 选择该 jar
3. 回到主菜单，进入「赛普克尔」星球

也可以在游戏「模组」→「从 GitHub 导入」里填：

```
rong-mo/sepker
```
